# Changelog

All notable changes to MLGWorks DevConsole are documented here.

## [1.0.0] - 2026-08-18

### Added

- Modular runtime console services with interface-based abstractions.
- Editor-managed command catalog and discovery workflow.
- Per-command and per-class enable/disable controls.
- Warning and dangerous command metadata.
- Command history, autocomplete, scrollback, logging, and built-in commands.
- Editor and PlayMode test coverage.
- Sample scene, command catalog, and demonstration command.
